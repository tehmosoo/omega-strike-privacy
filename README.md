# OMEGA STRIKE Privacy Policy

This repository hosts the public privacy policy page for **OMEGA STRIKE**.

It is intended to be published with **GitHub Pages** and used as the Privacy Policy URL in **App Store Connect** and **TestFlight**.

## Live page

After GitHub Pages is enabled, the privacy policy should be available at:

`https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPO_NAME/`

## Files

- `index.html` — the public privacy policy page
- `README.md` — this file

## How to publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings**.
3. Open **Pages** in the left sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select:
   - **Branch:** `main`
   - **Folder:** `/ (root)`
6. Click **Save**.

GitHub will then publish the site at:

`https://tehmosoo.github.io/omega-strike-privacy`

## How to use this in App Store Connect

Copy the GitHub Pages URL and paste it into:

- **Privacy URL** in App Store Connect
- optionally **Support URL** later if a support page is added
